# 🍎 Fruit Shop – Product Management Application

A full-stack Fruit Shop application developed to practice frontend and backend development, REST APIs, and CRUD operations.

## Features

- View all products
- Add new products
- Update existing products
- Delete products
- Search and filter products
- Product dashboard
- REST API integration
- Persistent data storage using JSON

## Technologies

### Frontend
- TypeScript
- JavaScript
- HTML5
- CSS3
- Fetch API

### Backend
- Node.js
- Express.js
- REST API
- JSON
